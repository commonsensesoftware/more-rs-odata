# Official grammar artifacts

These five files are unmodified OASIS 4.01 OS artifacts. Their source URLs and
SHA-256 hashes are recorded in [grammar-evidence.json](../../../docs/grammar-evidence.json).

Regenerate the family inventory and selected executable cases using
`scripts/inventory-grammar.ps1`. All ABNF test families have an explicit scope
classification. CSDL primitive/identifier cases execute without network access;
URL, query, HTTP and runtime families remain the responsibility of their respective
components. XSD and JSON-schema family inventory is not a claim of exhaustive
branch coverage or execution of a third-party schema validator.
